# Линия фронта

2D-тактика про позиционную войну в степи. Две вымышленные страны:
**Республика Велнария** (западные образцы: лучше ночные приборы, 155 мм, дроны с тепловизорами) и
**Кардагорская Федерация** (массированная артиллерия 152 мм, больше брони и пехоты, много FPV).

Режимы: **захват зон интереса**, **активный фронт** (живая линия фронта, обе стороны наступают),
**наступление и оборона**. Одиночная игра против ИИ и **сетевая игра** друг против друга (без ускорения времени).

## Запуск

```bash
cd nextlifea3
node game/server.js 8080        # без зависимостей: раздаёт игру + WebSocket для мультиплеера
# открыть http://localhost:8080/game/
```

В стартовом меню: сторона, режим, время начала (рассвет/день/сумерки/ночь), туман войны, сложность ИИ, длительность, карта (seed).
**Мультиплеер:** один игрок нажимает «Создать комнату» и сообщает 4-буквенный код, второй вводит код и «Войти»;
хост настраивает игру и жмёт «В бой». Хост считает симуляцию, гость получает состояние и отправляет приказы.
Для игры через интернет запустите `server.js` на машине с публичным адресом (или пробросьте порт).

Одиночную игру можно запустить и с любого статического сервера (`npx http-server`).

## Управление

Всё подписано в интерфейсе; полная справка — кнопка **?** или **F1**.

- **Камера:** ЛКМ + тянуть / WASD, колесо — зум, клик по миникарте
- **Выбор:** ЛКМ по подразделению или в списке слева (двойной клик — показать), Shift + рамка, Ctrl+A
- **ПКМ:** по земле — идти; по траншее — занять позицию; по зданию — занять здание (бойцы у окон)
- **Панель команд** (внизу, горячая клавиша в углу кнопки): Идти **M**, Занять **E**, Зачистить **C**, В подвал **V**, Копать **T**, Огонь **F**, Скрытно **G**, Стоп **X**; позы **N/Z/H/P**
- **Артиллерия:** выберите миномёт или гаубицу → «Огонь» → клик по цели. Кольца дальности, эллипс рассеяния и радиус поражения видны на карте; число выстрелов и взрыватель (контакт / воздушный подрыв) — в карточке
- **Боец вручную:** выберите отделение → клик по бойцу (или его карточке) → ПКМ
- **Слои:** Подписи **L**, Окопы (схема / подземный) **O**, Интерьеры **I**
- **Бой:** стрелковый бой идёт сам по обнаруженному противнику; режим огня **Q** (свободно / только в ответ / не стрелять)
- **Медицина:** медик отделения сам перевязывает; **R** — эвакуация тяжелораненых к санитарке/транспорту/в медпункт
- **Дроны** (расчёт БПЛА): **J** разведчик, **K** FPV-удар (клик по цели), **U** сброс гранат, **Y** вернуть
- **Время:** Пробел — пауза, 1–4 — скорость (только одиночная игра)
- **Меню ⋯:** удар 152 мм по клику (тест, **B**), траншея мгновенно, новая карта

## Устройство

| Файл | Что делает |
|---|---|
| `src/mapgen.js` | Процедурная генерация: река, пойма, балка с прудом, трасса, ж/д, город (кварталы, панельки, частный сектор, промзона, элеватор, вокзал, стадион), сёла (дворы, огороды, фермы), поля с лесополосами и грунтовками, следы войны |
| `src/render/draw.js` | Отрисовка чанка в спутниковом стиле: борозды, технологическая колея, тени зданий и деревьев, мосты, разметка, воронки |
| `src/render/chunks.js` | Кэш чанков 512×512 px по 6 уровням детализации |
| `src/spatial.js` | Пространственный индекс и растровая маска занятости (дорога, вода, застройка…) |
| `src/forts.js` | Фортификация: стрелковые траншеи-ломаные по опушке посадок, ячейки, «лисьи норы», ходы сообщения, блиндажи (2–4 наката, заглубление, выдерживаемый калибр), Г-образные входы, перекрытия брёвнами/сеткой, подземные ходы, капониры. Таблица защиты от осколков/подрыва в воздухе/дронов — под будущую артиллерию |
| `src/damage.js` | Следы боёв: сгоревшие участки посадок (обугленные/сухие/уничтоженные деревья), колеи гусениц, поля свежих и заросших воронок, подбитая техника |
| `src/sim/trenchgraph.js` | Граф траншей для пехоты: траншеи, ходы, входы в блиндажи, подземные ходы; поиск пути, выбор мест вокруг точки |
| `src/interiors.js` | Планировки: частный дом (прихожая, кухня, комнаты, погреб), панельный дом (подъезды, квартиры, техподвал), башня, школа/контора (коридор), ангар/цех/коровник (зал, ворота), сарай/гараж/теплица. Стены с проёмами, двери, окна, лестницы |
| `src/sim/localnav.js` | Точная сетка 0.4 м для пеших: стены, двери, вода — коллизии и обход зданий |
| `src/render/interiors.js` | Отрисовка интерьеров: полы, стены, окна, двери, лестницы, мебель, подвалы, этажность |
| `src/sim/artillery.js` | Артиллерия: миномёт 82 мм, гаубица 152 мм; развёртывание, время полёта, рассеяние, контакт / воздушный подрыв. Осколки: λ = N·A/(2π·d·h), A — открытость по позе и укрытию, стены и деревья гасят; Пуассон по попаданиям. Воронки, сломанные деревья, разрушение и обрушение зданий, обрушение блиндажей, уничтожение техники |
| `src/sim/factions.js` | Страны, их армии, техника (названия, броня, калибры), оружие бойцов и техники, ночные приборы |
| `src/sim/vision.js` | Обнаружение и туман войны: дальность по типу наблюдателя, ночь, освещённость, открытость цели, прямая видимость через кроны и здания |
| `src/sim/combat.js` | Стрелковый бой, подавление, противотанковое оружие, пушки техники, кровопотеря, работа медика |
| `src/sim/drones.js` | Дроны: разведчик, FPV-камикадзе, сбросчик; связь, батарея, огонь пехоты по дронам |
| `src/sim/modes.js` | Режимы, расстановка сил, зоны, поле контроля и линия фронта, условия победы |
| `src/sim/ai.js` | ИИ: укрытие под огнём, эвакуация, наступление к целям, артиллерия по скоплениям, дроны |
| `src/power.js` | День/ночь, электросеть: ЛЭП 110 кВ, главная подстанция, ТП, фидеры, фонари; разрушение → районы гаснут |
| `src/render/night.js` | Ночь и освещение (фонари, окна, пожары, вспышки), туман войны |
| `src/render/modes.js` | Линия фронта, серая зона, зоны интереса |
| `src/net.js`, `server.js` | Сетевая игра: снимки состояния, события мира (детерминированные по seed), приказы гостя; сервер без зависимостей |
| `src/render/forts.js` | Слои «схема окопов» и «подземный» |
| `src/sim/nav.js` | Сетка проходимости 8 м (степь, поле, пашня, посадка, дороги, вода, мосты, здания, балка) и A* с учётом типа движителя и скрытности |
| `src/sim/units.js` | Отряды, приказы, построение группы, движение с разгоном/поворотом/скоростью по местности. Без DOM — перенесётся на сервер |
| `src/render/units.js` | Тактические знаки (Синие — прямоугольник, Красные — ромб), техника сверху вблизи, пыль, маршруты |
| `src/main.js` | Камера, ввод, игровой цикл, подгрузка чанков, миникарта, панели |

Карта 9×6 км, генерация детерминирована по seed. Это пригодится для мультиплеера: всем игрокам достаточно передать число.
