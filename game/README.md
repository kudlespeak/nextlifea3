# Линия фронта — прототип (карта, отряды, окопы)

2D-стратегия про логистику, фронт и инфраструктуру. Вымышленный степной сеттинг, стороны **Синие** и **Красные**.

## Запуск

Нужен любой локальный веб-сервер (ES-модули не работают через `file://`):

```bash
cd nextlifea3
npx http-server -p 8080
# открыть http://localhost:8080/game/
```

Другая карта: `?seed=число` в адресе или кнопка «Новая карта».

## Управление

- ЛКМ + тянуть — перемещение карты, колесо / щипок — зум, WASD / стрелки
- ЛКМ по отряду — выбор (Ctrl — добавить), **Shift + рамка** — выбор группы, Ctrl+A — все свои, Esc — снять выбор
- **ПКМ** — приказ на движение (на телефоне: тап по земле при выбранных отрядах)
- **ПКМ по траншее** пехотой — занять позицию: бойцы расходятся по ячейкам лицом к противнику (несколько отделений — соседние участки)
- **C** — «Зачистить», затем клик по точке на траншее: отделение идёт колонной по траншеям (штурмовая двойка впереди), останавливается на изломах и развилках; пройденный участок отмечается
- **Боец вручную:** выберите отделение, приблизьте камеру и кликните по бойцу (или по кнопке с его ролью в панели) → ПКМ — куда идти. По траншеям и подземным ходам он идёт по ним, иначе — напрямую. Esc — снять выбор бойца
- **T** при выбранной пехоте / сапёрах / БТМ — приказ рыть траншею: отряды идут к месту и копают, траншея появляется кусками по 8 м (пехота ~12 м/ч, сапёры ~30 м/ч, БТМ ~350 м/ч). Без выбранных — мгновенно (тест)
- **ПКМ по зданию** пехотой — занять здание: бойцы расходятся к окнам (в первую очередь смотрящим на противника), остальные — по комнатам
- **V** — «В подвал», затем клик по зданию (или рядом): отделение спускается в подвал / погреб / смотровую яму
- **Позы:** кнопки в панели или **Z** стоя · **H** пригнуться · **P** лёжа · **N** авто. Применяется к выбранному бойцу или ко всему отделению. В авто: на марше — стоя, при зачистке — пригнувшись, на месте в поле — лёжа, в траншее / у окна / в подвале — в укрытии. Лёжа ползут медленно, пригнувшись — ~60% скорости
- **I** — показывать планировки зданий всегда (иначе крыша «снимается» при сильном приближении и над зданиями, где сидят свои)
- **G** — «Скрытно»: маршрут вдоль посадок и балок, избегая открытых полей и дорог
- **X** — стоп, **Пробел** — пауза, **1–4** — скорость времени (1×, 5×, 20×, 60×)
- **Tab** — сменить управляемую сторону (для теста, пока нет ИИ)
- **O** — вид окопов: скрыты (как на снимке) → схема (цветом стороны, видно под кронами) → подземный слой (блиндажи, накаты, подземные ходы)
- **B** — режим «Артудар»: клик оставляет воронки (они сохраняются на карте)
- **L** — подписи населённых пунктов
- Клик по миникарте или по отряду в панели — переход

## Устройство

| Файл | Что делает |
|---|---|
| `src/mapgen.js` | Процедурная генерация: река, пойма, балка с прудом, трасса, ж/д, город (кварталы, панельки, частный сектор, промзона, элеватор, вокзал, стадион), сёла (дворы, огороды, фермы), поля с лесополосами и грунтовками, следы войны |
| `src/render/draw.js` | Отрисовка чанка в спутниковом стиле: борозды, технологическая колея, тени зданий и деревьев, мосты, разметка, воронки |
| `src/render/chunks.js` | Кэш чанков 512×512 px по 6 уровням детализации |
| `src/spatial.js` | Пространственный индекс и растровая маска занятости (дорога, вода, застройка…) |
| `src/forts.js` | Фортификация: стрелковые траншеи-ломаные по опушке посадок, ячейки, «лисьи норы», ходы сообщения, блиндажи (2–4 наката, заглубление, выдерживаемый калибр), Г-образные входы, перекрытия брёвнами/сеткой, подземные ходы, капониры. Таблица защиты от осколков/подрыва в воздухе/дронов — под будущую артиллерию |
| `src/damage.js` | Следы боёв: сгоревшие участки посадок (обугленные/сухие/уничтоженные деревья), колеи гусениц, поля свежих и заросших воронок, подбитая техника |
| `src/sim/trenchgraph.js` | Граф траншей для пехоты: траншеи, ходы, входы в блиндажи, подземные ходы; поиск пути, выбор мест вокруг точки |
| `src/interiors.js` | Планировки: частный дом (прихожая, кухня, комнаты, погреб), панельный дом (подъезды, квартиры, техподвал), башня, школа/контора (коридор), ангар/цех/коровник (зал, ворота), сарай/гараж/теплица. Стены с проёмами, двери, окна, лестницы |
| `src/sim/localnav.js` | Точная сетка 0.4 м для пеших: стены, двери, вода — коллизии и обход зданий |
| `src/render/interiors.js` | Отрисовка интерьеров: полы, стены, окна, двери, лестницы, мебель, подвалы, этажность |
| `src/render/forts.js` | Слои «схема окопов» и «подземный» |
| `src/sim/nav.js` | Сетка проходимости 8 м (степь, поле, пашня, посадка, дороги, вода, мосты, здания, балка) и A* с учётом типа движителя и скрытности |
| `src/sim/units.js` | Отряды, приказы, построение группы, движение с разгоном/поворотом/скоростью по местности. Без DOM — перенесётся на сервер |
| `src/render/units.js` | Тактические знаки (Синие — прямоугольник, Красные — ромб), техника сверху вблизи, пыль, маршруты |
| `src/main.js` | Камера, ввод, игровой цикл, подгрузка чанков, миникарта, панели |

Карта 6×4 км, генерация детерминирована по seed. Это пригодится для мультиплеера: всем игрокам достаточно передать число.
